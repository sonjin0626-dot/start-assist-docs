# Start Assist Personal

Start Assist Personalは、予定した学習・開発を始める行動を支援する個人利用向けアプリです。指定したアプリを開くと、時間帯に応じた案内を表示します。制限画面からは意図的に抜けられます。医療上の診断や治療を目的とするものではありません。

## Googleドキュメント連携

利用者が選んだ非公開のGoogleドキュメント1件を読み取り、当日の研究ニュースを最大4件、端末内に保存して表示します。研究情報は「AI要約（未確認）」として扱います。

## 利用規約

本アプリは特定個人の利用を想定したツールであり、一般ユーザー向けの機能保証やサポートは提供しておりません。
